# Changelog

## Unreleased

- One name everywhere: help, messages, docs and the output prefix now say `angular-compat-matrix` (was `ng-matrix`). The `ng-matrix` command still works as an alias.
- The cache location is set with `ANGULAR_COMPAT_MATRIX_CACHE`. `NG_MATRIX_CACHE` still works as a fallback.
- The default cache folder is now `angular-compat-matrix` (Windows: `%LOCALAPPDATA%\angular-compat-matrix\Cache`). The old `ng-matrix` cache folder is no longer used and can be deleted.
